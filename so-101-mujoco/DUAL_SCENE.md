# Dual SO-101 scene

`assets/dual_scene.xml` is generated by `build_dual_scene.py` from the working
single-arm XML files. It copies the robot body tree and actuator block twice,
prefixes robot names/references with `left_` and `right_`, and shares the original
mesh, material, and default definitions. The source scene and grasp meshes are
not edited. There are no attachment constraints, welds, or inter-arm exclusions.

| Arm | Base position (m) | Base yaw | Actuator slots |
| --- | --- | --- | --- |
| Left | (0, -0.04, 0) | +90 degrees | 0–5 |
| Right | (0.36, 0.08, 0) | -90 degrees | 6–11 |

The existing HOME extends approximately 39 cm forward. These base orientations
park HOME along the outside edges instead of intersecting above the shared
workspace. Each selected arm turns inward to reach the same cube and destination.
Pickup is (0.18, 0, 0.015); desired final cube center is (0.18, 0.08, 0.015).

The adapter uses the original single-arm model only for local-frame IK calculations.
All physics, cube motion, contact forces, and success checks use the live dual model.
The selected six controls follow the existing `PickPlace` sequence. The inactive
six remain commanded to HOME, with normal servo dynamics; measured HOME deviation
and inter-arm contacts are checked every step. The only shared-controller changes
are an optional backend argument and an optional selected-geometry contact filter;
their defaults retain single-arm behavior.

From this directory, using the project environment:

```powershell
.\.venv\Scripts\python.exe dual_pick_place.py --arm right --runs 10
.\.venv\Scripts\python.exe dual_pick_place.py --arm left --runs 10
.\.venv\Scripts\python.exe dual_pick_place.py --arm right --viewer
.\.venv\Scripts\python.exe dual_pick_place.py --arm left --viewer
```

Headless operation is the default. These are repeated deterministic resets, not
randomized trials. Results are written to `dual_right_results.json` and
`dual_left_results.json`; any failed cycle produces a nonzero exit code. Each run
prints the selected arm, cube initial/final positions, target, XY error, and outcome.
The actuator list is verified and printed on startup, left first then right, each
in shoulder-pan, shoulder-lift, elbow-flex, wrist-flex, wrist-roll, gripper order.

Run `python test_dual_scene.py` to check model structure, jaw properties, prefixes,
and isolated control mapping. Run `python build_dual_scene.py` to regenerate the
dual XML after deliberately changing the single-arm source model.

Validated with ten deterministic resets per arm: right 10/10, left 10/10.
Right final position: `[0.17974344, 0.07977274, 0.01497091]` m (XY error 0.343 mm).
Left final position: `[0.18108742, 0.07997380, 0.01497091]` m (XY error 1.088 mm).
Inactive HOME deviation remained below 0.000541 rad, and no inter-arm collisions
occurred. The single-arm regression still produced its original 0.892 mm XY error.
